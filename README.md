# Elevate Home - E-Commerce Platform

A full-stack home decor e-commerce web application built with 
Java Servlets and JSP, featuring separate interfaces for admins 
and customers.

## What it covers
- Role-based access control for admins and customers
- Admin dashboard for inventory management, sales tracking 
  and low stock alerts
- Customer-facing product browsing, search and profile management
- MySQL database for storing product and user data

## Tech Stack
Java, JSP, Servlets, HTML, CSS, MySQL

## Requirements
- Java 8+
- Apache Tomcat
- MySQL
